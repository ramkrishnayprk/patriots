\section{Uncertainty and errors}

The B3-minus-B2 answer-support improvement is 0.0345. A paired 5,000-sample
bootstrap gives a 95\% confidence interval of $[0.0000, 0.1034]$. Since the
interval includes zero, this run does not establish an improvement.

Fifteen failures were deterministically labeled in the failure-analysis CSV.
The dominant issue is hallucination risk caused by missing refusal: answer retrieval succeeds, but the
evidence gate usually returns superficially related passages for questions
whose requested fact is absent. The next change should add field-level
support checks before generation, then rerun only the dev split.

\section{Reproduction and limitations}

The source CSV, validation output, per-item predictions, metrics, and errors
are stored in the evaluation directory. Commands are documented in that
directory's README. Answer correctness and citation validity are retrieval
support proxies; no generation-stage answers or citations were graded.
The official test split has not been run under the rubric's once-only rule
because human verification is incomplete.
