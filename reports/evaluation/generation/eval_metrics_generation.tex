\section{Evaluation scope}

This report evaluates the final grounded answer output rather than treating
retrieval coverage as an answer-correctness proxy. All 40 questions were
forced through the B3 semantic path: production hybrid retrieval, weak-query
escalation, evidence gating, and grounded OpenAI generation. Generated answers
were graded against the golden answer and evidence using a strict structured
judge. Citation validity additionally required syntactically valid context
numbers.

The generation and judge model was \path{gpt-4.1-mini}. The golden CSV is
still AI-drafted with \path{human_verified=false}; therefore these are
exploratory results, not official assessment scores.

There were 29 answerable and 11 non-answerable items. The final system
answered 25 of 29 answerable questions correctly, producing answer correctness
of 0.862. It correctly refused 10 of 11 non-answerable questions, producing a
correct-refusal rate of 0.909. It incorrectly refused 4 of 29 answerable
questions, producing an over-refusal rate of 0.138.

Citation validity was 0.793: 23 of 29 answerable items had a fully valid final
citation result. The two non-refusal citation errors were correct answers with
an additional citation to a context item that did not support the stated fact.
The remaining four citation failures were the four over-refusals.

These results demonstrate that perfect retrieval does not imply perfect final
answers. The principal final-stage problems are generator over-refusal,
extraneous citations, and failure to reject an unresolved conversational
reference.

\section{Latency and API usage}

Answer latency includes retrieval, escalation, and final generation, but
excludes the evaluation judge call. Median answer latency was 2432.3 ms and
p95 was 4093.7 ms.

The complete run, including answer grading, made 65 OpenAI calls and used
121,309 input tokens plus 3,828 output tokens, for 125,137 total tokens. USD
cost is not reported because model-specific pricing was not configured in the
evaluator.

\section{Uncertainty and limitations}

The answer-correctness estimate was 0.862 with a 95\% paired-bootstrap interval
of $[0.724, 0.966]$. Correct refusal was 0.909 with interval
$[0.727, 1.000]$, using 5,000 resamples.

\begin{itemize}
  \item The same model generated and graded answers, which can introduce
        self-judging bias.
  \item The golden set has not been human-verified.
  \item Questions were forced through semantic generation. Normal production
        auto-routing would answer several factual entity questions directly
        from structured records without an LLM.
  \item Retrieval metrics are document-ID metrics; citation and answer scores
        evaluate the final generated output.
  \item The test split was used exploratorily and is not the rubric's frozen,
        once-only official test run.
\end{itemize}
